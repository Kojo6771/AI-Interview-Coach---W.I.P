# AI Interview Coach 🚧 (Work in Progress)

AI Interview Coach is a collaborative project currently under development by a team of three developers. The goal is to build an intelligent interview preparation platform that helps students and job seekers practise for interviews using AI-powered feedback.

The application will allow users to upload their CV, choose a target role, and complete personalised mock interviews generated by an AI model. Responses will be evaluated to provide constructive feedback, identify areas for improvement, and track progress over time through an interactive dashboard.

## 🚀 Planned Features

* Secure user authentication
* CV upload and parsing
* AI-generated technical and behavioural interview questions
* AI-powered answer evaluation and feedback
* Performance scoring and interview analytics
* Personalised learning recommendations
* Interview history and progress tracking
* REST API with comprehensive documentation
* Responsive web interface

## 🛠️ Planned Tech Stack

* **Backend:** Python, FastAPI
* **Database:** PostgreSQL
* **AI:** OpenAI API / Local LLM
* **Authentication:** JWT
* **Caching & Background Tasks:** Redis, Celery
* **Testing:** Pytest
* **Containerisation:** Docker
* **CI/CD:** GitHub Actions
* **Frontend:** React

## 📌 Current Status

This project is actively being developed. Features are being implemented incrementally following Agile development practices, with each team member responsible for different components of the system.

Contributions, feedback, and suggestions are welcome as we continue building the platform.
